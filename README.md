Student Management System
A web-based Student Management System built using HTML, CSS, and JavaScript, hosted on the XAMPP Server environment. This project consists of two separate applications: one for teachers to manage student-related information and another for students to submit and maintain their personal details.
Project Overview
The Student Management System is designed to simplify the management of academic records and student information through an easy-to-use web interface. The system provides dedicated portals for teachers and students, enabling efficient data management and communication.
Features
Teacher Module


Manage student records.


View and update student information.


Monitor and organize academic data.


Maintain teacher-related details.


Student Module


Register and submit personal information.


Update profile details.


Access and manage individual records.


User-friendly interface for data entry.


Technologies Used


Frontend: HTML5, CSS3, JavaScript


Server Environment: XAMPP


Database: MySQL


Backend Integration: PHP (if applicable)


Objectives


Reduce manual record-keeping processes.


Provide centralized student information management.


Improve accessibility and organization of academic data.


Offer separate interfaces for teachers and students.


Installation


Install XAMPP and start Apache and MySQL services.


Clone this repository:
git clone https://github.com/your-username/student-management-system.git


Move the project folder to the htdocs directory.


Import the database file into MySQL using phpMyAdmin.


Open the project in your browser:
http://localhost/student-management-system
